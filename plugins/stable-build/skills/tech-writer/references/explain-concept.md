# Explain a concept

Create a clear explanation, with examples and diagrams, of a complex concept.

1. **Understand** what needs explaining and for whom.
2. **Structure** it in digestible, task-oriented sections. For Arc concepts use *What's happening* (the user's view) then *Under the hood* (the chain's view).
3. **Illustrate** with code examples and Mermaid diagrams where they help. Confirm every Arc detail through the arc-docs MCP and link the docs.arc.io page.
4. **Deliver** in plain language for that audience.

**Output:** a structured explanation that makes the complex simple, with its sources.
